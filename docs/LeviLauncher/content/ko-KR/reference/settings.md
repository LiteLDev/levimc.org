# 모든 설정

LeviLauncher 1.1.0 기준 Windows 버전 **설정** 페이지의 모든 설정을 탭별로 정리하고, [명령줄](./command-line)에서 바꿀 수 있는 설정에는 해당 `config` 키를 함께 적었습니다. 페이지 위쪽의 검색 필드로 설정 이름을 찾을 수 있습니다. 무엇을 바꿀지에 대한 조언은 [설정 및 개인화](../guide/settings-personalization)를 참조하세요.

## 일반 설정

| 설정 | 하는 일 | 키 |
| --- | --- | --- |
| **콘텐츠 경로 → 기본 루트** | 데이터 루트: 인스턴스, 다운로드, 백업이 들어 있는 폴더([폴더 및 파일](./files) 참조). **적용**은 새 폴더를 저장하고, **재설정**은 기본값으로 돌아갑니다. 아래에 **설치 프로그램**과 **버전** 폴더가 표시됩니다. 기존 데이터는 옮겨지지 않습니다. | `data-root` |
| **언어** | 런처의 언어. | — |
| **Discord Rich Presence** | Discord에 게임 상태를 표시합니다. 기본값은 켜짐. | `discord` |
| **Minecraft 실행 시** | Minecraft가 시작될 때 런처의 동작: **런처 최소화**(기본값), **런처 숨기기**, **런처 닫기** 또는 **런처 열어두기**. | `on-game-launch` |
| **Minecraft 종료 시** | Minecraft가 닫힐 때 런처의 동작: **런처 다시 열기**(기본값), **아무것도 하지 않음** 또는 **런처 닫기**. | `on-game-exit` |
| **닫을 때 트레이로 숨기기** | 닫기 버튼을 누르면 종료하는 대신 런처를 시스템 트레이로 숨깁니다. 최소화 버튼은 여전히 작업 표시줄로 최소화합니다. 기본값은 꺼짐. | `close-to-tray` |

## 개인화

이 탭은 네 부분으로 되어 있습니다. 개인화 설정(색상, 불투명도 등)은 밝은 테마와 어두운 테마에 대해 따로 저장됩니다(**모드별 설정**). **밝은 모드** 또는 **어두운 모드**를 골라 그중 하나를 편집하세요.

### 테마와 색

| 설정 | 하는 일 |
| --- | --- |
| **테마 모드** | **밝은 모드**, **어두운 모드**, **수동 일정**(**어두운 모드 시작 시간**과 **어두운 모드 종료 시간** 사이에 어두운 모드), **일출/일몰**(기기에서 계산한 현지 일출·일몰 시간 기준) 또는 **시스템 따르기**(Windows 설정). |
| **테마 색상** | 강조 색: **사전 설정 색상** 중 하나, **추가 색상** 중 하나 또는 **사용자 지정 색상**. |
| **기본 모드** | 대비를 위해 배경 이미지 아래에 까는 단색: **없음**, **테마 색상 따르기** 또는 **사용자 지정 색상**과 그 **기본 불투명도**. |

### 레이아웃과 모션

| 설정 | 하는 일 |
| --- | --- |
| **상단 탐색 바 사용** | 세로 사이드바 대신 위쪽 탐색 바를 씁니다. |
| **애니메이션 비활성화** | 인터페이스 전환 애니메이션을 끕니다. |

### 배경 이미지

| 설정 | 하는 일 |
| --- | --- |
| **배경 이미지** | 배경으로 쓸 이미지 폴더: **폴더 선택**, **폴더 열기**, **폴더 지우기**, 그리고 폴더에 사진이 여러 장이면 **다음 이미지**. |
| **맞춤 모드** | **스마트**, **중앙**, **맞춤**, **늘리기**, **타일**, **왼쪽 상단** 또는 **오른쪽 상단**. |
| **재생 순서** | **무작위** 또는 **순차적**(파일 이름의 자연 정렬 순서). |
| **배경 흐림**, **배경 밝기**, **배경 불투명도** | 이미지를 표시하는 방식. |

### 재질과 가독성

| 설정 | 하는 일 |
| --- | --- |
| **인터페이스 재질** | 배경 이미지 위의 탐색, 카드, 탭, 컨트롤, 팝업의 모습. **재질 프리셋**: **균형**(기본값), **선명** 또는 **단색**. |
| **인터페이스 불투명도**, **인터페이스 흐림**, **배경 오버레이** | 재질을 세밀하게 조정합니다. |
| **가독성 보호** | 테마, 이미지 밝기, 흐림에 따라 최소 표면 색조를 적용해 글자를 읽기 쉽게 유지합니다. |
| **이 테마 초기화** | 편집 중인 테마의 재질을 되돌립니다. |

각 항목의 자세한 설명은 [설정 및 개인화](../guide/settings-personalization#배경-이미지와-인터페이스-재질)의 "배경 이미지와 인터페이스 재질"에 있습니다.

## 패키지 관리

| 설정 | 하는 일 | 키 |
| --- | --- | --- |
| **캐시 지우기** | 패키지 관리자가 다운로드한 패키지 파일을 삭제합니다. 패키지 다운로드가 실패할 때 사용하세요. | `cache clean packages` |
| **미러 소스 사용** | 런처 업데이트, 패키지, 버전 목록을 중국 본토의 미러에서 다운로드합니다. 중국 본토 사용자는 기본값이 켜짐. | `mirror` |
| **GitHub 프록시** | 패키지 다운로드에 쓰는 GitHub 프록시로, **미러 소스 사용**이 켜져 있을 때 표시됩니다. 프리셋을 고르거나 **사용자 지정**으로 URL을 입력합니다. 비우면 기본값(`https://gh-proxy.org/https://github.com`)으로 돌아갑니다. | `github-proxy` |

## 정보

런처의 크레딧, 그리고 GitHub의 LiteLDev와 Discord 커뮤니티 링크.

## 명령줄 키 {#command-line-keys}

`LeviLauncher.exe config list`는 각 키의 값과 그 값의 출처를 보여 줍니다: `set`(저장됨), `default`(기본값), `auto`(감지됨) 또는 `lip`(lip 자체의 `config.toml`). `config set <key> <value>`는 키를 바꾸고, `config unset <key>`는 기본값으로 되돌립니다.

| 키 | 값 | 의미 |
| --- | --- | --- |
| `data-root` | 폴더 | 인스턴스, 다운로드, 백업이 있는 곳(기존 데이터는 옮겨지지 않음) |
| `default-instance` | 인스턴스 | 인스턴스를 지정하지 않았을 때 명령이 쓰는 인스턴스(`use`와 같음) |
| `mirror` | `on`, `off` | 중국 본토의 미러에서 다운로드(설정하지 않으면 지역으로 감지) |
| `github-proxy` | http(s) URL | 모드 다운로드용 GitHub 프록시(설정하지 않으면 미러가 켜져 있을 때 사용) |
| `beta-updates` | `on`, `off` | 런처의 사전 출시 업데이트 제공(기본값 `off`) |
| `discord` | `on`, `off` | 플레이 중 Discord Rich Presence 표시, 런처 창에서만(기본값 `on`) |
| `on-game-launch` | `minimize`, `hide`, `close`, `keep` | 게임이 시작될 때 런처 창의 동작(기본값 `minimize`) |
| `on-game-exit` | `reopen`, `keep`, `close` | 게임이 종료될 때 런처 창의 동작(기본값 `reopen`) |
| `close-to-tray` | `on`, `off` | 런처 창을 닫으면 트레이에 남음(기본값 `off`) |

`config list`와 `config get`이 표시하는 읽기 전용 키: `instances-dir`, `installers-dir`, `backups-dir`, `cache-dir`, `logs-dir`([폴더 및 파일](./files)의 폴더)와 `config-file`(설정 파일 `%APPDATA%\LeviLauncher\config.json`).
