# Папки и файлы

Все файлы и папки, которые читает и записывает версия LeviLauncher для Windows, по состоянию на LeviLauncher 1.1.0. Лаунчер ничего не пишет в системную временную папку (`%TEMP%`).

## Обзор

| Папка | Расположение | Содержимое |
| --- | --- | --- |
| Папка настроек | `%APPDATA%\LeviLauncher\` | Только `config.json`: маленький и перемещается вместе с вашим профилем Windows |
| Локальная папка | `%LOCALAPPDATA%\LeviLauncher\` | Журналы, аккаунт Microsoft, данные WebView2 окна; также корень данных по умолчанию |
| Корень данных | локальная папка, если вы не выбрали другую (**Базовая папка** в **Настройки → Основные настройки** или `config set data-root`) | `Instances\`, `Backups\`, `Cache\` |

```text
%APPDATA%\LeviLauncher\
  config.json                      настройки лаунчера
%LOCALAPPDATA%\LeviLauncher\        корень данных по умолчанию
  Logs\startup.log                 журнал лаунчера, а до него startup.1.log … startup.4.log
  Accounts\                        аккаунт Microsoft и записи устройства, зашифрованные для вашего пользователя Windows
  WebView2\                        данные окна лаунчера
  storage-migration.json           запись о переносе со старой структуры (см. ниже)
<корень данных>\
  Instances\<инстанс>\             один инстанс (см. ниже)
  Backups\
    Worlds\<инстанс>\<папка>_<мир>\<мир>_<yyyyMMdd-HHmmss>.mcworld
    Instances\<инстанс>\<инстанс>_<yyyyMMdd-HHmmss>.zip
  Cache\
    Installers\                    установщики игры, а также установщики Visual C++ и WebView2
    Updates\                       обновления лаунчера; удаляются после установки
    Downloads\                     файлы, скачанные для импорта; удаляются при запуске через 1 день
    Imports\                       файлы, переданные на импорт; удаляются при запуске через 1 день
    gdk-pending-versions.json
    gamertags.json                 gamertag профилей игроков, которые видел лаунчер
```

Всё в `Cache\` можно удалить без потерь. `LeviLauncher.exe cache clean` удаляет кэш пакетов, файлы, скачанные для импорта, и незавершённые загрузки, а `LeviLauncher.exe installer remove` удаляет скачанные установщики игры. Смена корня данных лишь указывает лаунчеру другую папку: существующие инстансы, загрузки и резервные копии не перемещаются.

## Папка инстанса

```text
Instances\<инстанс>\
  Minecraft.Windows.exe …          файлы игры этой сборки
  LeviLauncher.dll                 нативный загрузчик LeviLauncher (сборки x64)
  .levilauncher\                   состояние лаунчера в инстансе (скрытая)
    instance.json                  имя, версия игры, канал, изоляция и параметры запуска
    icon.ico                       значок инстанса, созданный из LargeLogo.png игры
    xbox-auth-key-v1               метка инстансов UWP для входа в Xbox
  .lip\                            состояние пакетов, установленных в инстанс (формат lip)
  mods\                            моды (см. «Как загружаются моды»)
  Minecraft Bedrock\               игровые данные при включённой изоляции (Preview: Minecraft Bedrock Preview)
```

Папки игровых данных инстансов с изоляцией и без неё описаны в [Изоляции инстансов](../concepts/isolation), а `mods\` — в [Как загружаются моды](../concepts/mod-loading).

## Вне папок LeviLauncher

| Путь | Что это |
| --- | --- |
| `Minecraft - <инстанс>.lnk` на рабочем столе | Ярлык инстанса (**Создать ярлык экземпляра на рабочем столе** или `instance shortcut`). Открывает лаунчер с `--launch=<инстанс>`. Записывается только на ваш рабочий стол, не на общий. |
| `%APPDATA%\lip\` | Настройки lip: `config.toml`, например его `github_proxy`, который читает и встроенный менеджер пакетов. |
| `%LOCALAPPDATA%\lip\Cache\` | Кэш пакетов встроенного менеджера пакетов, тот же, что у lip. **Очистить кэш** в **Настройки → Управление пакетами** очищает его. |
| `%APPDATA%\Minecraft Bedrock\`, `%APPDATA%\Minecraft Bedrock Preview\` | Общие игровые данные инстансов GDK без изоляции. |
| `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState\` (Preview: `Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe`) | Общие игровые данные инстансов UWP без изоляции. |

## Как записываются файлы

- Файл записывается рядом со своим конечным местом как `<имя>.<случайная строка>.tmp`, а затем переименовывается на место, поэтому наполовину записанный файл никогда не виден. Незавершённая загрузка, которую можно продолжить, хранится как `<имя>.partial.tmp`.
- Имена, которые вы выбираете (инстансы, миры), очищаются по правилам Windows: удаляются символы `<>:"/\|?*`, конечные точки и пробелы, а зарезервированные имена вроде `CON` или `NUL` обходятся.
- Файлы, которые создаёт лаунчер, называются `<имя>_<yyyyMMdd-HHmmss>.<расширение>`, например `MyWorld_20261107-142301.mcworld`.

## Старая структура

LeviLauncher до версии 1.1.0 хранил всё в `%APPDATA%\<имя программы>\` (например, `%APPDATA%\levilauncher.exe\`), с папками `versions\`, `backups\`, `installers\`, `updates\`, `logs\` и файлами `config.json`, `user_gamertag_map.json` и `gdk_pending_versions.json`. В инстансах были `version.json` и `LargeLogo.ico`.

При первом запуске LeviLauncher 1.1.0 или новее один раз переносит эти данные в описанную выше структуру, ничего не удаляя: данные на том же диске переименовываются на место, данные на другом диске копируются с сохранением оригинала, а старый `config.json` переименовывается в `config.migrated.json`. Выбранный вами корень данных остаётся на месте. Если что-то перенести нельзя (например, игра запущена из инстанса), все шаги отменяются, и лаунчер работает на старой структуре до следующего запуска. `storage-migration.json` записывает, что и куда было перенесено; после этого ярлыки на рабочем столе обновляются на новые места.
