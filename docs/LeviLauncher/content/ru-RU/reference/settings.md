# Все настройки

Все настройки страницы **Настройки** версии для Windows, вкладка за вкладкой, по состоянию на LeviLauncher 1.1.0, с ключом `config`, который меняет настройку из [командной строки](./command-line), если такой есть. Поле поиска вверху страницы находит настройку по названию. Советы о том, что менять, — в разделе [Настройки и персонализация](../guide/settings-personalization).

## Основные настройки

| Настройка | Что делает | Ключ |
| --- | --- | --- |
| **Пути к контенту → Базовая папка** | Корень данных: папка с инстансами, загрузками и резервными копиями (см. [Папки и файлы](./files)). **Применить** сохраняет новую папку, **Сбросить** возвращает папку по умолчанию. Ниже показаны папки **Установщики** и **Версии**. Существующие данные не перемещаются. | `data-root` |
| **Язык** | Язык лаунчера. | — |
| **Discord Rich Presence** | Показывает статус игры в Discord. По умолчанию включено. | `discord` |
| **При запуске Minecraft** | Что делает лаунчер при запуске Minecraft: **Сворачивать лаунчер** (по умолчанию), **Скрывать в системный трей**, **Закрывать лаунчер** или **Оставлять открытым**. | `on-game-launch` |
| **После закрытия Minecraft** | Что делает лаунчер при закрытии Minecraft: **Разворачивать лаунчер** (по умолчанию), **Ничего не делать** или **Закрывать лаунчер**. | `on-game-exit` |
| **Скрывать в трей при закрытии** | Кнопка закрытия прячет лаунчер в системный трей вместо выхода; кнопка сворачивания по-прежнему сворачивает на панель задач. По умолчанию выключено. | `close-to-tray` |

## Персонализация

Вкладка состоит из четырёх частей. Настройки персонализации (цвета, непрозрачность и т. д.) сохраняются отдельно для светлой и тёмной темы (**Настройки для каждого режима**): выберите **Светлая тема** или **Темная тема**, чтобы редактировать одну из них.

### Тема и цвета

| Настройка | Что делает |
| --- | --- |
| **Режим темы** | **Светлая тема**, **Темная тема**, **Расписание** (тёмная между **Временем начала ночного режима** и **Временем окончания ночного режима**), **Восход/Закат** (по местному времени восхода и заката, вычисляемому на устройстве) или **Как в системе** (настройка Windows). |
| **Цвет темы** | Акцентный цвет: один из **Стандартных цветов**, один из **Больше цветов** или **Пользовательский цвет**. |
| **Режим основы** | Сплошной цвет под фоновым изображением для контраста: **Нет**, **Цвет темы** или **Пользовательский цвет основы**, с **Непрозрачностью основы**. |

### Компоновка и анимация

| Настройка | Что делает |
| --- | --- |
| **Использовать верхнюю панель навигации** | Панель навигации сверху вместо вертикальной боковой панели. |
| **Отключить анимацию** | Выключает анимации переходов интерфейса. |

### Обои

| Настройка | Что делает |
| --- | --- |
| **Фоновое изображение** | Папка с изображениями для фона: **Выбрать изображение**, **Открыть папку**, **Очистить изображение** и **Следующее изображение**, когда в папке несколько картинок. |
| **Режим заполнения** | **Умное заполнение**, **По центру**, **Вписать**, **Растянуть**, **Замостить**, **Сверху слева** или **Сверху справа**. |
| **Порядок воспроизведения** | **Случайно** или **Последовательно** (естественный порядок имён файлов). |
| **Размытие фона**, **Яркость фона**, **Непрозрачность фона** | Как показывается изображение. |

### Материалы и читаемость

| Настройка | Что делает |
| --- | --- |
| **Материал интерфейса** | Вид навигации, карточек, вкладок, элементов управления и всплывающих окон поверх обоев. **Предустановки материала**: **Сбалансированный** (по умолчанию), **Прозрачный** или **Сплошной**. |
| **Непрозрачность интерфейса**, **Размытие интерфейса**, **Затемнение обоев** | Тонкая настройка материала. |
| **Защита читаемости** | Сохраняет текст читаемым с помощью минимального оттенка поверхностей, исходя из темы, яркости изображения и размытия. |
| **Сбросить эту тему** | Восстанавливает материал редактируемой темы. |

Каждая из них подробно описана в разделе [Настройки и персонализация](../guide/settings-personalization#обои-и-материал-интерфеиса).

## Управление пакетами

| Настройка | Что делает | Ключ |
| --- | --- | --- |
| **Очистить кэш** | Удаляет файлы пакетов, скачанные менеджером пакетов; используйте, если загрузка пакетов не удаётся. | `cache clean packages` |
| **Использовать зеркала** | Скачивает обновления лаунчера, пакеты и списки версий с зеркал в материковом Китае. По умолчанию включено для пользователей из материкового Китая. | `mirror` |
| **Прокси GitHub** | Прокси GitHub для загрузки пакетов, показывается, пока включено **Использовать зеркала**: предустановка или **Свой** для ввода URL. Пустое значение восстанавливает значение по умолчанию (`https://gh-proxy.org/https://github.com`). | `github-proxy` |

## Другие

| Настройка | Что делает |
| --- | --- |
| **Управление процессами → Сканировать процессы** | Показывает запущенные процессы Minecraft; **Завершить** завершает один, **Завершить все процессы** — все. Несохранённый игровой прогресс может быть потерян. |
| **Экспериментальные функции → Резервное копирование инстанса (экспериментально)** | Добавляет действия резервного копирования и восстановления в **Настройки инстанса**. При включении сначала показывается предупреждение. |

## Ключи командной строки {#command-line-keys}

`LeviLauncher.exe config list` показывает каждый ключ со значением и источником значения: `set` (сохранено), `default` (по умолчанию), `auto` (определено автоматически) или `lip` (собственный `config.toml` lip). `config set <key> <value>` меняет ключ, `config unset <key>` возвращает его к значению по умолчанию.

| Ключ | Значения | Значение |
| --- | --- | --- |
| `data-root` | папка | Где лежат инстансы, загрузки и резервные копии (существующие данные не перемещаются) |
| `default-instance` | инстанс | Инстанс, который используют команды, когда он не указан (то же, что `use`) |
| `mirror` | `on`, `off` | Скачивать с зеркал в материковом Китае (если не задано: определяется по региону) |
| `github-proxy` | URL http(s) | Прокси GitHub для загрузки модов (используется, пока включены зеркала, если не задан) |
| `beta-updates` | `on`, `off` | Предлагать предварительные обновления лаунчера (по умолчанию `off`) |
| `discord` | `on`, `off` | Показывать Discord Rich Presence во время игры, только из окна лаунчера (по умолчанию `on`) |
| `on-game-launch` | `minimize`, `hide`, `close`, `keep` | Что делает окно лаунчера при запуске игры (по умолчанию `minimize`) |
| `on-game-exit` | `reopen`, `keep`, `close` | Что делает окно лаунчера после выхода из игры (по умолчанию `reopen`) |
| `close-to-tray` | `on`, `off` | При закрытии окна лаунчер остаётся в трее (по умолчанию `off`) |

Ключи только для чтения, которые показывают `config list` и `config get`: `instances-dir`, `installers-dir`, `backups-dir`, `cache-dir`, `logs-dir` (папки из раздела [Папки и файлы](./files)) и `config-file` (файл настроек `%APPDATA%\LeviLauncher\config.json`).
