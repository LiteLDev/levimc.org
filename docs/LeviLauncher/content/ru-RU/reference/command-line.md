# Командная строка

`LeviLauncher.exe` без аргументов открывает окно лаунчера. С командой он работает в терминале и завершается; команды строятся по схеме `<существительное> <глагол>`:

```text
LeviLauncher.exe <command> [arguments] [flags]
```

На этой странице перечислены все команды LeviLauncher 1.1.0. `LeviLauncher.exe help <command>` выводит флаги и примеры каждой команды, а `LeviLauncher.exe help` — обзор. Вывод командной строки на английском языке.

```text
LeviLauncher.exe install latest --loader --use
LeviLauncher.exe play
LeviLauncher.exe mod install LiteLDev/LegacyMoney
LeviLauncher.exe world export "My World" -o D:\Backups
LeviLauncher.exe instance list --json
```

## Запуск из оболочки

`LeviLauncher.exe` — оконная программа, поэтому оболочки по умолчанию его не ждут. Если вывод нужен до возврата приглашения или нужен код возврата:

- в cmd используйте `start /wait LeviLauncher.exe ...`, затем прочитайте `%ERRORLEVEL%`;
- в PowerShell передайте вывод по конвейеру (`LeviLauncher.exe instance list | Out-String`) или используйте `Start-Process -Wait -NoNewWindow`.

Командная строка не открывает окно и может работать, пока окно открыто.

## Команды

### На каждый день

| Команда | Что делает |
| --- | --- |
| `play [<instance>]` | Запускает игру и ждёт появления её окна (псевдоним `launch`) |
| `install <version\|file>` | Скачивает и устанавливает Minecraft как новый инстанс (= `instance create`) |
| `use [<instance>]` | Задаёт или показывает инстанс по умолчанию |
| `stop [<instance>\|<pid>...]` | Закрывает запущенный Minecraft (= `process stop`) |

### Управление инстансом

| Команда | Что делает |
| --- | --- |
| `instance list [<filter>]` | Список установленных инстансов |
| `instance show [<instance>]` | Показывает настройки, регистрацию, загрузчик, игроков и количество контента инстанса (также `instance <instance>`) |
| `instance create <version\|file>` | Скачивает и устанавливает Minecraft как новый инстанс |
| `instance copy-data [<instance>] --from system\|<instance>` | Копирует игровые данные (миры, настройки) в инстанс с собственными данными |
| `instance rename <instance> <new-name>` | Переименовывает инстанс |
| `instance set [<instance>]` | Меняет настройки инстанса (консоль, режим редактора, собственные данные, аргументы, окружение, логотип) |
| `instance remove <instance>...` | Безвозвратно удаляет инстансы и всё в их папках |
| `instance register [<instance>]` | Заставляет Windows считать этот инстанс установленным Minecraft своего канала |
| `instance unregister [<instance>]` | Снимает регистрацию инстанса в Windows (игровые данные сохраняются) |
| `instance shortcut [<instance>]` | Создаёт ярлык на рабочем столе, запускающий инстанс, или удаляет его |
| `instance path [<instance>] [<kind>]` | Выводит папку инстанса (и при желании открывает её) |
| `mod list [<filter>]` | Список модов инстанса |
| `mod show <package>` | Показывает мод из каталога |
| `mod search [<words>]` | Ищет в каталоге модов LeviLamina |
| `mod install <package[@version]>...` | Устанавливает, обновляет или понижает версию модов из каталога |
| `mod update [<mod>...]` | Обновляет моды из каталога до новейшей версии |
| `mod import <file>...` | Добавляет моды из файлов `.mcmod`, `.zip` или `.dll` |
| `mod set <mod>` | Меняет манифест мода |
| `mod remove <mod>...` | Удаляет моды из инстанса |
| `mod enable <mod>... \| --all` | Включает моды |
| `mod disable <mod>... \| --all` | Выключает моды, не удаляя их |
| `mod path [<mod>]` | Выводит папку мода или папку модов инстанса |
| `loader versions` | Список версий LeviLamina, доступных для версии игры |
| `loader install [<version>]` | Устанавливает LeviLamina в инстанс или меняет её версию |
| `loader remove` | Удаляет LeviLamina из инстанса |
| `world list [<filter>]` | Список миров инстанса и игрока |
| `world import <file.mcworld>...` | Импортирует миры из файлов `.mcworld` |
| `world export <world>...` | Экспортирует (создаёт резервную копию) миры в файлы `.mcworld` |
| `world copy <world>...` | Копирует миры в другой инстанс |
| `world rename <world> <new-name>` | Меняет отображаемое имя мира |
| `world get <world> [<key>[/<sub>...]]` | Читает настройки мира из `level.dat` |
| `world set <world> <key>[/<sub>...]=<value>...` | Меняет настройки мира в `level.dat` |
| `world remove <world>...` | Безвозвратно удаляет миры |
| `pack list [<filter>]` | Список ресурс-паков, поведенческих паков и паков скинов |
| `pack import <file.mcpack\|file.mcaddon>...` | Устанавливает паки и аддоны из файлов `.mcpack` и `.mcaddon` |
| `pack copy <pack>... \| --all` | Копирует паки в другой инстанс |
| `pack remove <pack>...` | Удаляет установленные паки |
| `screenshot list` | Список скриншотов инстанса и игрока, новые сначала |
| `screenshot remove <name\|path>... \| --all` | Удаляет скриншоты |
| `server list [<filter>]` | Список сохранённых серверов с проверкой, в сети ли они |
| `player list` | Список профилей игроков инстанса GDK |
| `backup list [<instance>]` | Список резервных копий инстансов и миров (предварительная функция) |
| `backup create [<instance>]` | Создаёт резервную копию игровых данных и модов инстанса (предварительная функция) |
| `backup restore [<instance>] <archive.zip>` | Восстанавливает резервную копию инстанса (предварительная функция) |

### Поиск того, что установить

| Команда | Что делает |
| --- | --- |
| `installer search [<version>]` | Список сборок Minecraft, которые можно установить |
| `installer download <version>` | Скачивает установщик сборки, не устанавливая её |
| `installer list` | Список скачанных установщиков, включая незавершённые загрузки |
| `installer remove <version\|file>...` | Удаляет скачанные установщики, чтобы освободить место |
| `installer mirrors <version>` | Измеряет зеркала загрузки сборки GDK |
| `curseforge search [<words>]` | Ищет в CurseForge миры, аддоны, паки и скины (псевдоним существительного: `cf`) |
| `curseforge show <id>` | Показывает проект CurseForge |
| `curseforge categories` | Список классов и категорий CurseForge для фильтрации |
| `curseforge install <id>` | Скачивает файл CurseForge и импортирует его в инстанс |

### Этот ПК и лаунчер

| Команда | Что делает |
| --- | --- |
| `process list` | Список запущенных процессов Minecraft, включая запущенные не лаунчером (псевдоним: `ps`) |
| `process stop [<instance>\|<pid>...]` | Принудительно закрывает Minecraft (прогресс с последнего автосохранения теряется) |
| `account status` | Показывает вошедший аккаунт Microsoft и какие издания ему принадлежат |
| `account login` | Вход в аккаунт Microsoft или смена аккаунта |
| `account logout` | Забывает аккаунт Microsoft лаунчера |
| `config list` | Список настроек и папок лаунчера |
| `config get <key>` | Выводит значение настройки |
| `config set <key> <value>` | Меняет настройку |
| `config unset <key>` | Возвращает настройку к значению по умолчанию |
| `cache clean [packages\|downloads\|partial]...` | Освобождает место, занятое кэшами |
| `doctor [--fix [<fix>...]]` | Проверяет, что нужно Minecraft и модам на этом ПК; `--fix` исправляет (`vcruntime`, `gameinput`, `loader-migration`, `developer-mode`) |
| `self-update` | Обновляет сам LeviLauncher до новейшего релиза |
| `version` | Выводит информацию о версии |
| `help [<command>...]` | Справка по любой команде, с примерами |

Каждый глагол `list` также понимает `ls`, а каждый `remove` — `rm`. Настройки, которые читает и меняет `config`, перечислены в [Все настройки](./settings#command-line-keys).

### Версии и пакеты

- `<version>` у `install` и `installer` — сборка из `installer search`: точная (`1.21.50.07`), префикс с точками (`1.21.50` — новейшая `1.21.50.x`; `1.21.5` ей не соответствует) или `latest`. `<file>` — локальный `.msixvc`, `.appx`, `.msix`, `.appxbundle` или `.msixbundle`.
- `<package>` у `mod install` — `owner/repo`, `github.com/owner/repo` или URL, при необходимости с `#variant` и `@version`.

## Глобальные флаги

Эти флаги работают со всеми командами:

| Флаг | Значение |
| --- | --- |
| `-i`, `--instance <name>` | Инстанс, с которым работать |
| `-p`, `--player <id\|gamertag>` | Профиль игрока в инстансах GDK |
| `--json` | Машиночитаемый вывод в stdout |
| `-q`, `--quiet` | Выводить только идентификаторы; без прогресса и уведомлений |
| `-v`, `--verbose` | Больше подробностей и журнал лаунчера в stderr |
| `-y`, `--yes` | Отвечать «да» на подтверждения |
| `--no-input` | Никогда не задавать вопросов |
| `-h`, `--help` | Справка по команде |
| `--version` | Вывести версию |

**Какой инстанс:** `-i`, иначе переменная окружения `LEVILAUNCHER_INSTANCE`, иначе инстанс по умолчанию (`use`), иначе единственный инстанс. **Какой игрок:** `-p`, иначе `LEVILAUNCHER_PLAYER`, иначе единственный профиль, иначе профиль вошедшего аккаунта.

## Вывод

- Результаты идут в stdout. Прогресс, уведомления и ошибки — в stderr; ошибка выводится как `error:` с `hint:` и кодом ошибки, например `[ERR_GAME_RUNNING]`.
- `--json` выводит один документ JSON: массив для списков и объект в остальных случаях, с ключами в camelCase, временем в RFC 3339 и размерами в байтах.
- `-q` выводит только идентификаторы, по одному в строке.

## Коды возврата

| Код | Значение |
| --- | --- |
| 0 | Успешно |
| 1 | Ошибка |
| 2 | Ошибка использования |
| 3 | Не найдено |
| 4 | Конфликт (например, игра запущена) |
| 5 | Вход или лицензия |
| 6 | Сеть |
| 7 | Выполнено частично |
| 8 | Нужно изменение системы или права администратора |
| 9 | Превышено время ожидания |
| 10 | Отменено |
| 130 | Прервано (Ctrl-C) |

`launch --wait-exit` вместо этого возвращает собственный код возврата игры.

## Параметры окна

Эти аргументы открывают окно вместо выполнения команды:

| Аргумент | Действие |
| --- | --- |
| `--launch=<instance>` | Открывает лаунчер и запускает инстанс; его используют ярлыки на рабочем столе. Если лаунчер уже запущен, инстанс запускается в нём. |
| `--debug` | Дополнительно показывает журнал лаунчера в окне консоли (также работают `debug`, `-debug` и `/debug`). |
