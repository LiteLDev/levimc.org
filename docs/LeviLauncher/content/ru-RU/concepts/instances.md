# Инстансы и версии игры

LeviLauncher устанавливает каждую копию Minecraft как **инстанс**: одну версию игры со своим именем, своими настройками и, если нужно, своими игровыми данными. Можно держать несколько инстансов одновременно — одной версии игры или разных — и запускать нужный. Приложение показывает их на странице **Инстансы**.

## Что такое инстанс

=== "Windows"

    Инстанс — это папка внутри папки `Instances` лаунчера (см. [Папки и файлы](../reference/files)). Имя инстанса — это имя папки. В папке находятся:

    - файлы игры одной сборки Minecraft, распакованные из её установщика;
    - `.levilauncher\instance.json` — то, что лаунчер знает об инстансе: версия игры, канал, хранит ли он собственные игровые данные, и параметры запуска (консоль, режим редактора, аргументы запуска, переменные окружения);
    - `mods\` — моды инстанса, и `.lip\` — состояние пакетов, установленных встроенным менеджером пакетов (см. [Как загружаются моды](./mod-loading));
    - собственные игровые данные инстанса (миры, паки, настройки), если для него включена [изоляция](./isolation).

    Моды всегда принадлежат одному инстансу. Игровые данные принадлежат одному инстансу, только когда включена изоляция; иначе инстанс использует игровые данные, которые Minecraft обычно использует на этом ПК.

=== "Android"

    Инстанс — это официальный APK Minecraft, импортированный в LeviLauncher. Он работает внутри лаунчера, без установки в систему. Minecraft из Google Play (1.21.80 или новее) всё равно должен быть установлен на устройстве; LeviLauncher показывает его рядом с импортированными версиями.

    Изоляция версий хранит миры, паки и настройки импортированной версии отдельно от установленной версии из Google Play. Импортированным версиям для запуска часто нужна изоляция.

## Release и Preview

Каждая сборка Minecraft относится к **каналу**:

| Канал | Что это |
| --- | --- |
| Release | Стабильная игра, которой пользуется большинство игроков. |
| Preview | Сборки будущих версий для тестирования. Чаще ломают миры, паки или моды. |
| Beta | Тестовые сборки, выпускавшиеся только для UWP. <Badge platform="windows" /> |

В Windows у Release и Preview своя папка игровых данных (`Minecraft Bedrock` и `Minecraft Bedrock Preview`), поэтому инстанс Preview без изоляции не делит миры с инстансом Release.

## Сборки GDK и UWP <Badge platform="windows" />

Minecraft для Windows выходил в двух форматах пакетов, и LeviLauncher устанавливает оба. Если версия есть в обоих, выбирается GDK.

| | GDK | UWP |
| --- | --- | --- |
| Установщик | `.msixvc`, скачивается с зеркала, которое LeviLauncher измеряет и выбирает | `.appx` / `.msix` (или пакет-бандл), скачивается из Центра обновления Windows |
| Для установки | Вход в аккаунт Microsoft, которому принадлежит Minecraft | — |
| Для запуска | Microsoft Gaming Services и Microsoft GameInput | Режим разработчика Windows, чтобы зарегистрировать пакет в Windows |
| Общие игровые данные | `%APPDATA%\Minecraft Bedrock` (Preview: `Minecraft Bedrock Preview`), по папке на профиль игрока в `Users\` | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState` (Preview: `Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe`) |
| Изоляция | Все версии | Версии x64 1.19.70.2 и новее |
| LeviLamina | Устанавливается LeviLauncher на поддерживаемых версиях | LeviLauncher не устанавливает |
| Аргументы запуска и переменные окружения | Да | Нет |

Импортированный локальный установщик (`.msixvc`, `.appx`, `.msix`, `.appxbundle` или `.msixbundle`) устанавливается как GDK или UWP в зависимости от расширения.

### Профили игроков {#player-profiles}

Инстанс GDK хранит миры, скриншоты и список серверов для каждого **профиля игрока**: это папка в `Users\` с ID игрока в качестве имени, показываемая с его gamertag, если лаунчер его знает. Ресурс-паки и поведенческие паки общие для всех профилей (`Users\Shared\`); паки скинов общие начиная с игры 1.26, а до неё хранились по профилям. У инстансов UWP профилей нет.

## Регистрация в Windows <Badge platform="windows" /> {#registration-with-windows}

Windows знает один установленный Minecraft на канал. **Регистрация** инстанса заставляет Windows считать его этим Minecraft: меню «Пуск», ссылки `minecraft://` и функции Xbox начинают использовать его. Регистрация заменяет текущего владельца места Release или Preview (игру из Microsoft Store или другой инстанс), его данные сохраняются. Регистрация и её снятие никогда не трогают игровые данные.

Инстансы UWP регистрируются автоматически при запуске. С зарегистрированного инстанса нужно снять регистрацию, прежде чем его можно будет переименовать или удалить.
