# Изоляция инстансов

Minecraft хранит миры, паки и настройки в одной папке игровых данных на устройство. **Изоляция инстанса** (в приложении: **Включить изоляцию** в **Настройках инстанса** и **Изоляция инстанса** при установке версии) даёт инстансу собственную папку игровых данных внутри инстанса. Командная строка называет эти два режима *own data* (собственные данные) и *shared data* (общие данные).

## Общие и собственные данные

=== "Windows"

    Инстанс **без изоляции** использует игровые данные, которые Minecraft обычно использует на этом ПК: те же миры, паки и настройки, что и игра из Microsoft Store и любой другой инстанс того же типа без изоляции.

    Инстанс **с изоляцией** хранит игровые данные в своей папке. Его миры, ресурс-паки, поведенческие паки, паки скинов, скриншоты, список серверов и настройки игры отделены от всех остальных инстансов и от игры из Microsoft Store.

    | Инстанс | Общие данные (изоляция выключена) | Собственные данные (изоляция включена) |
    | --- | --- | --- |
    | GDK, Release | `%APPDATA%\Minecraft Bedrock` | `<инстанс>\Minecraft Bedrock` |
    | GDK, Preview | `%APPDATA%\Minecraft Bedrock Preview` | `<инстанс>\Minecraft Bedrock Preview` |
    | UWP, Release | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState` | `<инстанс>\Minecraft Bedrock` |
    | UWP, Preview | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe\LocalState` | `<инстанс>\Minecraft Bedrock Preview` |
    | UWP, Beta | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState` | `<инстанс>\Minecraft Bedrock Beta` |

    `<инстанс>` — папка инстанса в `Instances` (см. [Папки и файлы](../reference/files)). В папке данных GDK игра хранит данные каждого игрока в `Users\` (см. [профили игроков](./instances#player-profiles)); в папке данных UWP — в `games\com.mojang\`.

=== "Android"

    Изоляция версий хранит игровые данные версии (миры, паки и настройки) отдельно от других версий и от Minecraft, установленного из Google Play. Изменение этого параметра для одного инстанса не затрагивает другие. Импортированным версиям для запуска часто нужна изоляция.

## Как это работает <Badge platform="windows" />

Сама игра ничего не знает об инстансах. При установке инстанса LeviLauncher кладёт свой загрузчик `LeviLauncher.dll` рядом с исполняемым файлом игры (см. [Как загружаются моды](./mod-loading)). Когда игра запускается с включённой изоляцией, загрузчик перенаправляет папки, в которых игра ищет свои данные (папки данных приложения и временную папку), в папку данных инстанса. Ничего не копируется и не связывается: игра просто читает и пишет там.

Что изоляция не меняет:

- **Моды** всегда относятся к инстансу и лежат в его папке `mods\`, с изоляцией или без.
- **Аккаунт Microsoft** и настройки самого лаунчера одинаковы для всех инстансов.
- **Регистрация** в Windows (см. [Инстансы и версии игры](./instances#registration-with-windows)) не зависит от изоляции.

## Ограничения <Badge platform="windows" />

- Инстансы GDK поддерживают изоляцию на всех версиях; инстансы UWP — начиная с версии 1.19.70.2 и только x64.
- Включение изоляции ничего не копирует: инстанс начинает с пустыми игровыми данными. Чтобы начать с существующих данных, выберите копирование данных при установке версии (из игры, установленной на этом ПК, или из другого изолированного инстанса того же типа) или скопируйте их позже командой `LeviLauncher.exe instance copy-data` (GDK).
- После выключения изоляции инстанс снова использует общие данные; его собственная папка данных остаётся в папке инстанса.
- Удаление инстанса удаляет его папку, **включая миры его собственных данных**. Сначала сделайте резервную копию важных миров (см. [Инструменты для миров](../guide/world-tools)).
- Контент можно копировать из одного инстанса в другой только в инстанс с собственными данными или в инстанс UWP, который не использует ту же папку данных.

## Когда использовать

Изоляция полезна, когда вам нужно:

- разные наборы контента для разных версий
- более безопасное тестирование модов или версий Minecraft Preview
- меньший риск того, что одна сборка повлияет на другую

Удобная схема: один изолированный инстанс Release для обычной игры, один изолированный инстанс Preview только при необходимости и один временный тестовый инстанс для модов или диагностики.
