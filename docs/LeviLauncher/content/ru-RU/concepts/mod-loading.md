# Как загружаются моды

У Minecraft Bedrock нет собственной поддержки модов: мод — это нативный код, который загрузчик помещает в процесс игры при её запуске. Эта страница объясняет, какие загрузчики использует LeviLauncher, где лежат моды и как связаны разные способы добавить мод.

## Где лежат моды <Badge platform="windows" />

У каждого инстанса есть папка `mods\` (см. [Папки и файлы](../reference/files)). Каждый мод — это папка в ней с файлом `manifest.json`, который описывает мод:

| Поле | Значение |
| --- | --- |
| `name` | Имя мода. |
| `entry` | Файл, который загружает загрузчик, относительно папки мода (`.dll`). |
| `version` | Версия мода. |
| `type` | Какой загрузчик его загружает: `preload-native` — нативный загрузчик LeviLauncher; у модов для LeviLamina свои типы. |
| `author` | Автор (необязательно). |

Моды принадлежат одному инстансу. На них не влияет [изоляция](./isolation), которая касается только игровых данных.

**Выключение мода** (в **Управлении модами** или командой `LeviLauncher.exe mod disable`) переименовывает его `manifest.json` в `manifest.json.close`; включение возвращает прежнее имя. Файлы мода остаются на месте, а загрузчик, который ищет `manifest.json`, больше не находит мод.

## Два загрузчика <Badge platform="windows" />

### Нативный загрузчик LeviLauncher

Когда LeviLauncher устанавливает или подготавливает инстанс, он кладёт свой загрузчик `LeviLauncher.dll` рядом с исполняемым файлом игры и добавляет его в импорты исполняемого файла, чтобы Windows загружала его вместе с игрой. Это работает для сборок x64, как GDK, так и UWP; на этом же держится [изоляция](./isolation).

При запуске игры нативный загрузчик обходит папки в `mods\` в порядке их имён и загружает `entry` каждого мода с `type`, равным `preload-native`. Папки без `manifest.json` и моды других типов пропускаются. Если у инстанса есть другой предзагрузчик (`preloader.dll` рядом с игрой), нативный загрузчик оставляет всю загрузку модов ему. Нативному загрузчику нужна среда выполнения Visual C++ (x64), которую LeviLauncher проверяет и предлагает установить.

### LeviLamina

[LeviLamina](https://levimc.org/LeviLamina/) — загрузчик модов LeviMC. Большинство модов на [LeviMC Mods](https://levimc.org/mods/) — это моды LeviLamina: им нужна LeviLamina в версии, поддерживающей версию игры инстанса. LeviLauncher устанавливает LeviLamina в инстансы GDK поддерживаемых версий (переключатель **Установить LeviLamina** при установке версии или вкладка **Загрузчик** в **Настройках инстанса**) как пакет встроенного менеджера пакетов.

## Три способа добавить мод <Badge platform="windows" />

| Что вы добавляете | Что делает LeviLauncher |
| --- | --- |
| Мод из **LeviMC Mods** (или `mod install owner/repo`) | Устанавливает его как пакет встроенным менеджером пакетов, совместимым с [lip](https://github.com/LiteLDev/lip): скачивает релиз для этой платформы, устанавливает пакеты, от которых он зависит, и записывает его в `.lip\state.json` инстанса. Если моду нужна LeviLamina, а установленная не подходит (или её нет), сначала устанавливается совместимая LeviLamina. Такие моды можно обновлять и удалять как пакеты. |
| Пакет `.mcmod` (или `.zip`) | Распаковывает его в новую папку в `mods\`. В архиве должен быть `manifest.json`. |
| Отдельный `.dll` | Кладёт его в новую папку в `mods\` и пишет для него `manifest.json`: по умолчанию имя файла как имя, `preload-native` как тип и `0.0.0` как версию. |

Пакет указывает, где он работает, полями `side` (`client` или `server`) и `platform` (например, `win-x64`) в своём `lip.toml` и в `.lip\state.json`. Для клиента LeviLauncher устанавливает вариант мода `client`, если он есть, иначе вариант по умолчанию. Подробности, включая миграцию старых пакетов, — в разделе [Моды и интеграции](../guide/mods-integrations).

## Android <Badge platform="android" />

Версия для Android загружает нативные моды: библиотеки `.so`, которые работают в процессе игры. Держите сборки с модами в изолированных версиях и устанавливайте моды только из надёжных источников. Чтобы сделать свой, следуйте [Android native mods](https://levimc.org/LeviLamina/developer_guides/android/) в документации LeviLamina.
