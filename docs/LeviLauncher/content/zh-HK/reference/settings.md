# 全部設定

Windows 版 **設定** 頁面中的每一項設定（以 LeviLauncher 1.1.0 為準），按分頁排列；能在[命令列](./command-line)中修改的，同時給出對應的 `config` 鍵。頁面頂部的搜尋框可以按名稱尋找設定。關於該改甚麼，見[設定與個人化](../guide/settings-personalization)。

## 基礎設定

| 設定 | 作用 | 鍵 |
| --- | --- | --- |
| **內容路徑 → 根目錄** | 資料根目錄：存放實例、下載和備份的資料夾（見[資料夾與檔案](./files)）。**套用** 保存新資料夾，**恢復預設** 回到預設位置。下方顯示 **安裝器目錄** 和 **實例目錄**。已有資料不會被移動。 | `data-root` |
| **語言** | 啟動器的語言。 | — |
| **Discord 遊戲狀態** | 在 Discord 上顯示你的遊戲狀態。預設開啟。 | `discord` |
| **Minecraft 啟動時** | Minecraft 啟動時啟動器的動作：**最小化啟動器**（預設）、**隱藏到系統匣**、**關閉啟動器** 或 **保持啟動器開啟**。 | `on-game-launch` |
| **Minecraft 關閉時** | Minecraft 關閉時啟動器的動作：**重新打開啟動器**（預設）、**保持原樣** 或 **關閉啟動器**。 | `on-game-exit` |
| **關閉視窗時隱藏到系統匣** | 按下關閉按鈕時把啟動器隱藏到系統匣而不是結束；最小化按鈕仍然最小化到工作列。預設關閉。 | `close-to-tray` |

## 個性化

這個分頁分為四部分。個性化設定（顏色、不透明度等）對日間和夜間主題分別保存（**按模式分別設定**）：選擇 **日間模式** 或 **夜間模式** 來編輯其中一個。

### 主題與配色

| 設定 | 作用 |
| --- | --- |
| **外觀模式** | **日間模式**、**夜間模式**、**手動設置時間**（在 **夜間模式開始時間** 與 **夜間模式結束時間** 之間使用夜間模式）、**日出日落**（根據本地日出日落時間切換，在裝置上計算）或 **跟隨系統**（Windows 的設定）。 |
| **主題色** | 強調色：從 **預设顏色**、**更多顏色** 中選擇，或使用 **自定義顏色**。 |
| **底色模式** | 在背景圖片下面加一層純色以增強對比度：**無**、**跟隨主題色** 或 **自定義顏色**，以及 **底色不透明度**。 |

### 版面與動效

| 設定 | 作用 |
| --- | --- |
| **使用頂部導航欄** | 用頂部導航欄代替垂直側邊欄。 |
| **停用動畫** | 關閉介面的過渡動畫。 |

### 桌布

| 設定 | 作用 |
| --- | --- |
| **背景圖片** | 用作背景的圖片資料夾：**選擇圖片**、**開啟資料夾**、**清除圖片**，資料夾中有多張圖片時可用 **換一張**。 |
| **適應方式** | **智能**、**居中**、**適應**、**拉伸**、**平鋪**、**左上** 或 **右上**。 |
| **播放順序** | **亂序** 或 **順序**（按檔案名稱的自然順序）。 |
| **背景模糊**、**背景亮度**、**背景不透明度** | 圖片的顯示方式。 |

### 材質與可讀性

| 設定 | 作用 |
| --- | --- |
| **介面材質** | 導航、卡片、分頁、控制項和彈出層疊在桌布上的樣子。**材質預設**：**均衡**（預設）、**通透** 或 **純色**。 |
| **介面不透明度**、**介面模糊**、**背景遮罩** | 微調材質。 |
| **可讀性保護** | 根據主題、圖片亮度和模糊程度設定最低的表面著色，讓文字保持清晰。 |
| **重設目前主題** | 恢復正在編輯的主題的材質。 |

各項的詳細說明見[設定與個人化](../guide/settings-personalization#桌布與介面材質)。

## 套件管理

| 設定 | 作用 | 鍵 |
| --- | --- | --- |
| **清理快取** | 刪除套件管理器下載的套件檔案；套件下載失敗時使用。 | `cache clean packages` |
| **使用鏡像來源** | 從中國內地的鏡像下載啟動器更新、套件和版本列表。中國內地用戶預設開啟。 | `mirror` |
| **GitHub 代理** | 下載套件時使用的 GitHub 代理，在 **使用鏡像來源** 開啟時顯示：選擇一個預設，或選擇 **自訂** 輸入 URL。留空則恢復預設值（`https://gh-proxy.org/https://github.com`）。 | `github-proxy` |

## 其他設定

| 設定 | 作用 |
| --- | --- |
| **進程管理 → 掃描進程** | 列出正在執行的 Minecraft 程序；**結束** 結束一個，**結束所有進程** 結束全部。未保存的遊戲進度可能遺失。 |
| **實驗性功能 → 實例備份（實驗性）** | 在 **實例設定** 中加入備份與還原操作。開啟時會先顯示一段警告。 |

## 命令列鍵 {#command-line-keys}

`LeviLauncher.exe config list` 顯示每個鍵的值以及值的來源：`set`（已保存）、`default`（預設）、`auto`（自動偵測）或 `lip`（lip 自己的 `config.toml`）。`config set <key> <value>` 修改一個鍵，`config unset <key>` 把它恢復為預設值。

| 鍵 | 取值 | 含義 |
| --- | --- | --- |
| `data-root` | 一個資料夾 | 實例、下載和備份所在的位置（已有資料不會被移動） |
| `default-instance` | 一個實例 | 未指定實例時指令使用的實例（與 `use` 相同） |
| `mirror` | `on`、`off` | 從中國內地的鏡像下載（未設定時按地區自動判斷） |
| `github-proxy` | 一個 http(s) URL | 下載模組時使用的 GitHub 代理（鏡像開啟時使用，除非已設定） |
| `beta-updates` | `on`、`off` | 提供啟動器的預發佈更新（預設 `off`） |
| `discord` | `on`、`off` | 遊戲時顯示 Discord 遊戲狀態，僅限啟動器視窗（預設 `on`） |
| `on-game-launch` | `minimize`、`hide`、`close`、`keep` | 遊戲啟動時啟動器視窗的動作（預設 `minimize`） |
| `on-game-exit` | `reopen`、`keep`、`close` | 遊戲結束時啟動器視窗的動作（預設 `reopen`） |
| `close-to-tray` | `on`、`off` | 關閉啟動器視窗時保留在系統匣中（預設 `off`） |

唯讀鍵，由 `config list` 和 `config get` 顯示：`instances-dir`、`installers-dir`、`backups-dir`、`cache-dir`、`logs-dir`（即[資料夾與檔案](./files)中的資料夾）以及 `config-file`（設定檔 `%APPDATA%\LeviLauncher\config.json`）。
