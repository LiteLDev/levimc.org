# すべての設定

Windows 版の **設定** ページにあるすべての設定を、タブごとにまとめています（LeviLauncher 1.1.0 時点）。[コマンドライン](./command-line)から変更できる設定には、対応する `config` のキーも記しています。ページ上部の検索欄で設定名から探せます。何を変えるとよいかは[設定とカスタマイズ](../guide/settings-personalization)を参照してください。

## 基本設定

| 設定 | 内容 | キー |
| --- | --- | --- |
| **コンテンツパス → 基本ルート** | データルート。インスタンス、ダウンロード、バックアップを置くフォルダーです（[フォルダーとファイル](./files)を参照）。**適用** で新しいフォルダーを保存し、**リセット** で既定に戻します。下に **インストーラー** と **バージョン** のフォルダーが表示されます。既存のデータは移動しません。 | `data-root` |
| **言語** | ランチャーの言語。 | — |
| **Discord Rich Presence** | Discord にゲームの状態を表示します。既定はオン。 | `discord` |
| **Minecraft 起動時** | Minecraft の起動時にランチャーがすること: **ランチャーを最小化**（既定）、**タスクトレイに最小化**、**ランチャーを閉じる**、**ランチャーを開いたままにする**。 | `on-game-launch` |
| **Minecraft 終了時** | Minecraft の終了時にランチャーがすること: **ランチャーを再表示**（既定）、**何もしない**、**ランチャーを閉じる**。 | `on-game-exit` |
| **閉じる時にトレイに隠す** | 閉じるボタンで終了せず、ランチャーをシステムトレイに隠します。最小化ボタンは引き続きタスクバーに最小化します。既定はオフ。 | `close-to-tray` |

## 個人用設定

このタブは 4 つの部分に分かれています。個人用設定（色、不透明度など）はライトテーマとダークテーマで別々に保存されます（**モードごとの設定**）。**ライトモード** か **ダークモード** を選んで、どちらかを編集します。

### テーマと配色

| 設定 | 内容 |
| --- | --- |
| **外観モード** | **ライトモード**、**ダークモード**、**スケジュール**（**ダークモード開始時間** から **ダークモード終了時間** までダーク）、**日の出/日の入り**（デバイス上で計算した現地の日の出・日の入り時刻に従う）、**システムに従う**（Windows の設定）。 |
| **テーマカラー** | アクセントカラー: **プリセットカラー**、**その他の色** から選ぶか、**カスタムカラー**。 |
| **底色モード** | コントラストのために背景画像の下に敷く単色: **なし**、**テーマカラーに従う**、**カスタム色** と、その **底色の不透明度**。 |

### レイアウトとモーション

| 設定 | 内容 |
| --- | --- |
| **トップナビゲーションバーを使用** | 縦のサイドバーの代わりに上部のナビゲーションバーを使います。 |
| **アニメーションを無効化** | インターフェイスの遷移アニメーションをオフにします。 |

### 壁紙

| 設定 | 内容 |
| --- | --- |
| **背景画像** | 背景に使う画像のフォルダー: **画像を選択**、**フォルダを開く**、**画像をクリア**、フォルダーに複数の画像があるときは **次の画像**。 |
| **フィッティングモード** | **スマート**、**中央**、**フィット**、**引き伸ばし**、**並べる**、**左上**、**右上**。 |
| **再生順序** | **ランダム** または **順次**（ファイル名の自然順）。 |
| **背景のぼかし**、**背景の明るさ**、**背景の不透明度** | 画像の表示方法。 |

### マテリアルと読みやすさ

| 設定 | 内容 |
| --- | --- |
| **インターフェイスのマテリアル** | 壁紙の上に重なるナビゲーション、カード、タブ、コントロール、ポップアップの見た目。**マテリアルのプリセット**: **バランス**（既定）、**クリア**、**ソリッド**。 |
| **インターフェイスの不透明度**、**インターフェイスのぼかし**、**壁紙のオーバーレイ** | マテリアルを細かく調整します。 |
| **読みやすさの保護** | テーマ、画像の明るさ、ぼかしに応じて面に最低限の色を付け、文字を読みやすく保ちます。 |
| **このテーマをリセット** | 編集中のテーマのマテリアルを元に戻します。 |

それぞれの詳しい説明は[設定とカスタマイズ](../guide/settings-personalization#壁紙とインターフェイスのマテリアル)にあります。

## パッケージ管理

| 設定 | 内容 | キー |
| --- | --- | --- |
| **キャッシュを削除** | パッケージマネージャーがダウンロードしたパッケージファイルを削除します。パッケージのダウンロードに失敗するときに使います。 | `cache clean packages` |
| **ミラーソースを使用** | ランチャーの更新、パッケージ、バージョン一覧を中国本土のミラーからダウンロードします。中国本土のユーザーは既定でオン。 | `mirror` |
| **GitHub プロキシ** | パッケージのダウンロードに使う GitHub プロキシ。**ミラーソースを使用** がオンのときに表示されます。プリセットを選ぶか、**カスタム** で URL を入力します。空にすると既定値（`https://gh-proxy.org/https://github.com`）に戻ります。 | `github-proxy` |

## その他

| 設定 | 内容 |
| --- | --- |
| **プロセス管理 → プロセスをスキャン** | 実行中の Minecraft のプロセスを一覧表示します。**終了** で 1 つ、**すべてのプロセスを終了** ですべてを終了します。保存していないゲームの進行状況は失われることがあります。 |
| **実験的機能 → インスタンスバックアップ（実験的）** | **インスタンス設定** にバックアップと復元の操作を追加します。オンにするとまず警告が表示されます。 |

## プライバシー

| 設定 | 内容 |
| --- | --- |
| **利用状況の分析（Google Analytics）** | ランチャーの改善に役立つ利用状況の統計を送信します。いつでもオフにできます。**Google Analytics 利用規約** と **Google プライバシーポリシー** へのリンクがあります。 |

## アップデート

| 設定 | 内容 | キー |
| --- | --- | --- |
| **ベータ版アップデートを受信** | ランチャーのプレリリース版の更新も受け取ります。既定はオフ。 | `beta-updates` |
| **現在のバージョン → 更新を確認** | ランチャーのバージョンを表示し、新しいバージョンを探します。 | `self-update --check` |

## コマンドラインのキー {#command-line-keys}

`LeviLauncher.exe config list` は、各キーの値とその値の出どころを表示します: `set`（保存済み）、`default`（既定）、`auto`（自動検出）、`lip`（lip 自身の `config.toml`）。`config set <key> <value>` でキーを変更し、`config unset <key>` で既定に戻します。

| キー | 値 | 意味 |
| --- | --- | --- |
| `data-root` | フォルダー | インスタンス、ダウンロード、バックアップの置き場所（既存のデータは移動しない） |
| `default-instance` | インスタンス | インスタンスを指定しないときにコマンドが使うインスタンス（`use` と同じ） |
| `mirror` | `on`、`off` | 中国本土のミラーからダウンロード（未設定なら地域で自動判定） |
| `github-proxy` | http(s) の URL | Mod のダウンロード用の GitHub プロキシ（未設定ならミラーがオンのときに使用） |
| `beta-updates` | `on`、`off` | ランチャーのプレリリース版の更新を提供（既定 `off`） |
| `discord` | `on`、`off` | プレイ中に Discord Rich Presence を表示。ランチャーのウィンドウからのみ（既定 `on`） |
| `on-game-launch` | `minimize`、`hide`、`close`、`keep` | ゲーム起動時のランチャーのウィンドウの動作（既定 `minimize`） |
| `on-game-exit` | `reopen`、`keep`、`close` | ゲーム終了時のランチャーのウィンドウの動作（既定 `reopen`） |
| `close-to-tray` | `on`、`off` | ランチャーのウィンドウを閉じるとトレイに残る（既定 `off`） |

`config list` と `config get` が表示する読み取り専用のキー: `instances-dir`、`installers-dir`、`backups-dir`、`cache-dir`、`logs-dir`（[フォルダーとファイル](./files)のフォルダー）と `config-file`（設定ファイル `%APPDATA%\LeviLauncher\config.json`）。
