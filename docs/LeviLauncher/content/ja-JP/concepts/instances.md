# インスタンスとゲームバージョン

LeviLauncher は Minecraft の各コピーを**インスタンス**としてインストールします。インスタンスとは、独自の名前と独自の設定、そして必要なら独自のゲームデータを持つ 1 つのゲームバージョンです。同じゲームバージョンでも異なるゲームバージョンでも、複数のインスタンスを並べて置き、必要なものを起動できます。アプリでは **インスタンス** ページに一覧表示されます。

## インスタンスとは

=== "Windows"

    インスタンスは、ランチャーの `Instances` フォルダー内のフォルダーです（[フォルダーとファイル](../reference/files)を参照）。インスタンスの名前はフォルダーの名前です。フォルダーには次のものが入っています。

    - インストーラーから展開した、Minecraft の 1 つのビルドのゲームファイル
    - `.levilauncher\instance.json`: ランチャーがインスタンスについて記録している情報。ゲームバージョン、チャンネル、独自のゲームデータを持つかどうか、起動オプション（コンソール、エディターモード、起動引数、環境変数）
    - `mods\`: インスタンスの Mod。`.lip\`: 内蔵パッケージマネージャーでインストールしたパッケージの状態（[Mod の読み込み](./mod-loading)を参照）
    - [隔離](./isolation)が有効なときの、インスタンス独自のゲームデータ（ワールド、パック、設定）

    Mod は常に 1 つのインスタンスに属します。ゲームデータが 1 つのインスタンスに属するのは隔離が有効なときだけで、そうでなければインスタンスはこの PC で Minecraft が普段使うゲームデータを使います。

=== "Android"

    インスタンスは、LeviLauncher にインポートした公式の Minecraft APK です。システムにインストールせず、ランチャーの中で動作します。デバイスには引き続き Google Play の Minecraft（1.21.80 以降）がインストールされている必要があり、LeviLauncher はそれをインポートしたバージョンと並べて表示します。

    バージョン分離は、インポートしたバージョンのワールド、パック、設定を、インストール済みの Google Play 版から切り離します。インポートしたバージョンの起動には、分離が必要なことがよくあります。

## 正式版とプレビュー版

Minecraft のビルドはどれも 1 つの**チャンネル**に属します。

| チャンネル | 内容 |
| --- | --- |
| Release（正式版） | ほとんどのプレイヤーが使う安定版のゲーム。 |
| Preview（プレビュー版） | 今後のバージョンのテスト用ビルド。ワールド、パック、Mod が壊れることが多くなります。 |
| Beta | UWP 向けにだけ公開されたテストビルド。 <Badge platform="windows" /> |

Windows では、正式版とプレビュー版はそれぞれ専用のゲームデータフォルダー（`Minecraft Bedrock` と `Minecraft Bedrock Preview`）を持つため、隔離していないプレビュー版インスタンスでも正式版インスタンスとワールドを共有しません。

## GDK ビルドと UWP ビルド <Badge platform="windows" />

Windows 版 Minecraft は 2 つのパッケージ形式で公開されてきており、LeviLauncher はどちらもインストールします。同じバージョンが両方の形式で存在する場合は GDK が選ばれます。

| | GDK | UWP |
| --- | --- | --- |
| インストーラー | `.msixvc`。LeviLauncher が計測して選んだミラーからダウンロード | `.appx` / `.msix`（またはバンドル）。Windows Update からダウンロード |
| インストールに必要 | Minecraft を所有する、サインイン済みの Microsoft アカウント | — |
| 実行に必要 | Microsoft Gaming Services と Microsoft GameInput | パッケージを Windows に登録するための Windows の開発者モード |
| 共有ゲームデータ | `%APPDATA%\Minecraft Bedrock`（プレビュー版: `Minecraft Bedrock Preview`）。`Users\` の下にプレイヤープロファイルごとに 1 フォルダー | `%LOCALAPPDATA%\Packages\Microsoft.MinecraftUWP_8wekyb3d8bbwe\LocalState`（プレビュー版: `Microsoft.MinecraftWindowsBeta_8wekyb3d8bbwe`） |
| 隔離 | すべてのバージョン | 1.19.70.2 以降の x64 バージョン |
| LeviLamina | 対応バージョンで LeviLauncher がインストール | LeviLauncher はインストールしない |
| 起動引数と環境変数 | 対応 | 非対応 |

インポートしたローカルのインストーラー（`.msixvc`、`.appx`、`.msix`、`.appxbundle`、`.msixbundle`）は、拡張子に応じて GDK または UWP としてインストールされます。

### プレイヤープロファイル {#player-profiles}

GDK インスタンスは、ワールド、スクリーンショット、サーバーリストを**プレイヤープロファイル**ごとに保存します。プレイヤープロファイルは `Users\` の下にあるプレイヤー ID 名のフォルダーで、ランチャーがゲーマータグを知っていればゲーマータグで表示されます。リソースパックとビヘイビアパックはすべてのプロファイルで共有され（`Users\Shared\`）、スキンパックはゲーム 1.26 以降で共有、それより前はプロファイルごとです。UWP インスタンスにはプロファイルはありません。

## Windows への登録 <Badge platform="windows" /> {#registration-with-windows}

Windows はチャンネルごとにインストール済みの Minecraft を 1 つだけ認識します。インスタンスを**登録**すると、Windows はそれをその Minecraft として扱い、スタートメニュー、`minecraft://` リンク、Xbox の機能がそのインスタンスを使うようになります。登録すると正式版またはプレビュー版の枠の現在の持ち主（Microsoft Store のゲームまたは別のインスタンス）が置き換えられ、そのデータは保持されます。登録と登録解除がゲームデータに触れることはありません。

UWP インスタンスは起動時に自動で登録されます。登録済みのインスタンスは、名前を変更したり削除したりする前に登録を解除する必要があります。
