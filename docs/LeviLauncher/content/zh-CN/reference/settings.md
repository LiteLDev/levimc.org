# 全部设置

Windows 版 **设置** 页面中的每一项设置（以 LeviLauncher 1.1.0 为准），按选项卡排列；能在[命令行](./command-line)中修改的，同时给出对应的 `config` 键。页面顶部的搜索框可以按名称查找设置。关于该改什么，见[设置与个性化](../guide/settings-personalization)。

## 基础设置

| 设置 | 作用 | 键 |
| --- | --- | --- |
| **内容路径 → 根目录** | 数据根目录：存放实例、下载和备份的文件夹（见[文件夹与文件](./files)）。**应用** 保存新文件夹，**恢复默认** 回到默认位置。下方显示 **安装包目录** 和 **实例目录**。已有数据不会被移动。 | `data-root` |
| **语言** | 启动器的语言。 | — |
| **Discord 游戏状态** | 在 Discord 上显示你的游戏状态。默认开启。 | `discord` |
| **Minecraft 启动时** | Minecraft 启动时启动器的动作：**最小化启动器**（默认）、**隐藏到系统托盘**、**关闭启动器** 或 **保持启动器开启**。 | `on-game-launch` |
| **Minecraft 关闭时** | Minecraft 关闭时启动器的动作：**重新打开启动器**（默认）、**保持原样** 或 **关闭启动器**。 | `on-game-exit` |
| **关闭窗口时隐藏到托盘** | 点击关闭按钮时把启动器隐藏到系统托盘而不是退出；最小化按钮仍然最小化到任务栏。默认关闭。 | `close-to-tray` |

## 个性化

这个选项卡分为四部分。个性化设置（颜色、不透明度等）对日间和夜间主题分别保存（**按模式分别设置**）：选择 **日间模式** 或 **夜间模式** 来编辑其中一个。

### 主题与配色

| 设置 | 作用 |
| --- | --- |
| **外观模式** | **日间模式**、**夜间模式**、**手动设置时间**（在 **夜间模式开始时间** 与 **夜间模式结束时间** 之间使用夜间模式）、**日出日落**（根据本地日出日落时间切换，在设备上计算）或 **跟随系统**（Windows 的设置）。 |
| **主题色** | 强调色：从 **预设颜色**、**更多颜色** 中选择，或使用 **自定义颜色**。 |
| **底色模式** | 在背景图片下面加一层纯色以增强对比度：**无**、**跟随主题色** 或 **自定义颜色**，以及 **底色不透明度**。 |

### 布局与动效

| 设置 | 作用 |
| --- | --- |
| **使用顶部导航栏** | 用顶部导航栏代替垂直侧边栏。 |
| **禁用动画** | 关闭界面的过渡动画。 |

### 壁纸

| 设置 | 作用 |
| --- | --- |
| **背景图片** | 用作背景的图片文件夹：**选择文件夹**、**打开文件夹**、**清除文件夹**，文件夹中有多张图片时可用 **换一张**。 |
| **自适应方式** | **智能**、**居中**、**适应**、**拉伸**、**平铺**、**左上对齐** 或 **右上对齐**。 |
| **播放顺序** | **随机** 或 **顺序**（按文件名的自然顺序）。 |
| **背景模糊**、**背景亮度**、**背景不透明度** | 图片的显示方式。 |

### 材质与可读性

| 设置 | 作用 |
| --- | --- |
| **界面材质** | 导航、卡片、选项卡、控件和弹出层叠在壁纸上的样子。**材质预设**：**均衡**（默认）、**通透** 或 **纯色**。 |
| **界面不透明度**、**界面磨砂**、**背景遮罩** | 微调材质。 |
| **可读性保护** | 根据主题、图片亮度和模糊程度设置最低的表面着色，让文字保持清晰。 |
| **重置当前主题** | 恢复正在编辑的主题的材质。 |

各项的详细说明见[设置与个性化](../guide/settings-personalization#背景图片与界面材质)。

## 包管理

| 设置 | 作用 | 键 |
| --- | --- | --- |
| **清理缓存** | 删除包管理器下载的软件包文件；软件包下载失败时使用。 | `cache clean packages` |
| **使用镜像源** | 从中国大陆的镜像下载启动器更新、软件包和版本列表。中国大陆用户默认开启。 | `mirror` |
| **GitHub 代理** | 下载软件包时使用的 GitHub 代理，在 **使用镜像源** 开启时显示：选择一个预设，或选择 **自定义** 输入 URL。留空则恢复默认值（`https://gh-proxy.org/https://github.com`）。 | `github-proxy` |

## 其他设置

| 设置 | 作用 |
| --- | --- |
| **进程管理 → 扫描进程** | 列出正在运行的 Minecraft 进程；**结束** 结束一个，**结束所有进程** 结束全部。未保存的游戏进度可能丢失。 |
| **实验性功能 → 实例备份（实验性）** | 在 **实例设置** 中加入备份与恢复操作。开启时会先显示一段警告。 |

## 命令行键 {#command-line-keys}

`LeviLauncher.exe config list` 显示每个键的值以及值的来源：`set`（已保存）、`default`（默认）、`auto`（自动检测）或 `lip`（lip 自己的 `config.toml`）。`config set <key> <value>` 修改一个键，`config unset <key>` 把它恢复为默认值。

| 键 | 取值 | 含义 |
| --- | --- | --- |
| `data-root` | 一个文件夹 | 实例、下载和备份所在的位置（已有数据不会被移动） |
| `default-instance` | 一个实例 | 未指定实例时命令使用的实例（与 `use` 相同） |
| `mirror` | `on`、`off` | 从中国大陆的镜像下载（未设置时按地区自动判断） |
| `github-proxy` | 一个 http(s) URL | 下载模组时使用的 GitHub 代理（镜像开启时使用，除非已设置） |
| `beta-updates` | `on`、`off` | 提供启动器的预发布更新（默认 `off`） |
| `discord` | `on`、`off` | 游戏时显示 Discord 游戏状态，仅限启动器窗口（默认 `on`） |
| `on-game-launch` | `minimize`、`hide`、`close`、`keep` | 游戏启动时启动器窗口的动作（默认 `minimize`） |
| `on-game-exit` | `reopen`、`keep`、`close` | 游戏退出时启动器窗口的动作（默认 `reopen`） |
| `close-to-tray` | `on`、`off` | 关闭启动器窗口时保留在托盘中（默认 `off`） |

只读键，由 `config list` 和 `config get` 显示：`instances-dir`、`installers-dir`、`backups-dir`、`cache-dir`、`logs-dir`（即[文件夹与文件](./files)中的文件夹）以及 `config-file`（设置文件 `%APPDATA%\LeviLauncher\config.json`）。
