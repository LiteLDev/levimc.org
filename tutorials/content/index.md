# LeviMC Tutorials

Each tutorial starts from a clean PC and ends with something that works — a modded server, a modded game, your
first mod. The project docs hold the guides and reference for when you want to go further.

## Run a server

- [Your first server](server/first-server.md) — install lip, set up Bedrock Dedicated Server with LeviLamina and
  start it, with the lip interface.
- [A server from the command line](server/command-line.md) — the same server with lip's commands, for scripts and
  remote machines.
- [A server in Docker](server/docker.md) — LeviLamina in a container, its world in a volume; no lip or Wine on the
  host.
- [Install mods on your server](server/install-mods.md) — find mods in the LeviMC Mods catalog, install, update and
  remove them with lip.
- [Let friends join your server](server/let-friends-join.md) — on your home network, then over the internet, with or
  without a public IP.

## Play

- [Play with mods on Windows](play/play-with-mods.md) — install LeviLauncher, add a game version and launch it with
  mods.
- [Play with mods on Android](play/play-with-mods-android.md) — install LeviLauncher on your phone, launch your
  Google Play game and add a mod.

## Make mods

- [Your first LeviLamina mod](develop/first-levilamina-mod.md) — create a C++ mod from the template, build it and
  load it on your server.
- [Your first script plugin](develop/first-script-plugin.md) — write a JavaScript or Lua plugin for
  LegacyScriptEngine.
- [Your first Android native mod](develop/first-android-mod.md) — build a C++ mod from the template, pack it and
  import it into LeviLauncher on your phone.
- [Publish your mod with lip](develop/publish-a-package.md) — turn your mod into a lip package that anyone can
  install with one command.

## Automate

- [Drive the game client with Be.D.D.](automate/bedd.md) — run Minecraft Bedrock in the background under a script
  of yours.
- [Your first bedboo bot](automate/first-bedboo-bot.md) — a JavaScript bot that joins your server, chats and walks
  to you.
